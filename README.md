# Mohamed's Portfolio

A personal portfolio website showcasing my front-end development skills, projects, and experience with modern web technologies.

## 🌐 About

I'm a Front-End Developer passionate about building modern, responsive, and user-friendly web experiences.

I enjoy turning ideas into functional websites with clean code, thoughtful design, and smooth interactions.

## 🚀 Features

- **Modern UI:** Clean and premium design.
- **Responsive Design:** Optimized for different screen sizes.
- **Dark / Light Mode:** Switch between themes.
- **Motion Controls:** Enable or disable website animations.
- **Scroll Reveal:** Smooth reveal animations while scrolling.
- **Projects Showcase:** A collection of my front-end projects.
- **Contact Form:** Contact me directly through WhatsApp.
